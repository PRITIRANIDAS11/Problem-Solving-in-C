# Problem Solving in C 🚀

Welcome to my C programming repository! This repository contains various C programs that I wrote while practicing problem-solving and logic building.

## 📁 Included Programs

* **Basic Operations:** Calculator, Number Printing, Sum calculations
* **Conditional Logic:** Leap Year Check, Grade Calculation

## 🛠️ How to Run
1. Clone the repository or download the `.c` file.
2. Open in VS Code, Code::Blocks, or compile using GCC.
